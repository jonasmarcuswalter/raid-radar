Wanna create your own raid route?

Raid Before You Bonk, now for your own GPX.

Custom Raid Radar routes will be built through ChatGPT, not through a public upload form. That keeps private GPX data private and lets every rider choose how much intelligence they want to spend on the route.

Current status

Private beta / connector setup in progress

The self-serve builder is being prepared as an embedded ChatGPT App. Until that connector is live, this page explains the flow and keeps the public site honest: no broken upload button, no pretend automation.

How it works

  1. 1. Once live, attach GPX in ChatGPT The embedded Raid Radar builder checks that the file is parseable and stays within the current 1000 km limit.
  2. 2. Choose the build Pick route name, privacy, target repo, and how deep the raid research should go.
  3. 3. Build the route app Codex prepares the offline route cockpit with GPX line, Next Raid, raid options, gaps, and map-pack logic where feasible.

What you need

  • A GPX file Up to 1000 km for now, with enough track points to build a useful route.
  • A ChatGPT / OpenAI account The route intelligence runs from the rider’s own account or connected Codex environment.
  • A GitHub account Private route requests should live in a rider-owned repo, not in the public Raid Radar demo repo.

Your data stays yours

Your GPX should not land in Jonas’s public Raid Radar repository. The planned builder stores private route requests in your own repository or private build storage.

OpenAI/Codex usage also belongs to the rider creating the route. Raid Radar provides the template, brand, and build flow; the private route intelligence runs on the user-owned resource.

Choose raid intelligence

Fast A quick raid scan for simple rides and lower effort.
Balanced The default: useful stops, gaps, and source checks without going wild.
Deep More research for tricky timing, Sundays, night riding, and fallback stops.
Ultra Maximum paranoia mode for long routes where bad resupply decisions hurt.

How it embeds

The builder appears inside ChatGPT as an embedded Apps SDK / MCP interface. You choose the GPX and settings there, ChatGPT can call the Raid Radar tools, and the resulting route request is prepared for your own private build target.

The public website stays the finished-route launcher: it shows prepared route apps, but it does not ask for private GPX files or credentials.
