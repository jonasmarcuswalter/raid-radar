How this becomes a full route app

The downloadable package uses the same request shape as the future ChatGPT App: GPX, route metadata, selected intelligence level, privacy choice, and a Codex build prompt.

The next production step is an authenticated connector that writes this package into the rider’s private repo and launches the build there. Until then, this local builder is the safe working handoff.
